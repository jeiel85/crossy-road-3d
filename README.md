# 🐔 Crossy Road 3D (길건너 친구들 3D)

Three.js를 활용하여 외부 에셋(이미지, 3D 모델) 없이 100% 코드로 구현된 절차적 3D 복셀 스타일의 **Crossy Road 웹 게임**입니다.

## 🕹️ 라이브 데모 (Live Demo)
👉 **[게임 플레이하기 (GitHub Pages)](https://jeiel85.github.io/crossy-road-3d/)**

---

## ✨ 주요 특징 (Features)

1. **절차적 3D 복셀 그래픽 (Procedural Voxel Graphics)**
   - Three.js BoxGeometry를 활용하여 닭, 차량(승용차/화물트럭), 나무, 통나무, 기차, 독수리를 코드로 직접 생성
   - OrthographicCamera(직교 카메라)를 적용한 깔끔하고 왜곡 없는 아이소메트릭(Isometric) 쿼터뷰
   - 부드러운 카메라 추적(Lerp) 및 실시간 그림자 효과

2. **무한 지형 및 장애물 생성 (Endless World Generation)**
   - 풀밭 (안전지대, 나무 장애물)
   - 도로 (좌우 방향 및 속도가 다른 자동차/트럭)
   - 강 (떠내려가는 통나무)
   - 철길 (경고등 점멸 후 고속 질주하는 기차)
   - 메모리 최적화를 위한 지나간 후방 레인 자동 정리

3. **게임 메커니즘 및 물리 (Game Mechanics)**
   - 통통 튀는 포물선 점프와 스쿼시 & 스트레치 애니메이션
   - 강물 익사 판정 및 통나무 탑승 동기화
   - 차량 및 기차 AABB 충돌 판정
   - 5.5초 이상 제자리에 머물 경우 덮치는 독수리 시스템

4. **자체 합성 사운드 (Web Audio API)**
   - 외부 오디오 파일 의존 없이 Web Audio API를 활용한 점프, 충돌, 기차 경적, 물 풍덩, 독수리 활강 합성음 탑재

5. **기록 및 반응형 UI**
   - 로컬 스토리지 기반 최고 기록(Best Score) 연동
   - 키보드(방향키/WASD) 및 모바일 스와이프/탭 터치 조작 완벽 지원

---

## 🛠️ 실행 방법 (Local Run)

별도의 빌드 과정이나 패키지 설치 없이 브라우저에서 index.html 파일을 열기만 하면 즉시 플레이할 수 있습니다.
