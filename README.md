# 🐔 Crossy Road 3D - Expanded Edition (길건너 친구들 3D)

Three.js를 활용하여 외부 에셋(이미지, 3D 모델) 없이 100% 코드로 구현된 절차적 3D 복셀 스타일의 **Crossy Road 확장판 웹 게임**입니다.

## 🕹️ 라이브 데모 (Live Demo)
👉 **[게임 플레이하기 (GitHub Pages)](https://jeiel85.github.io/crossy-road-3d/)**

---

## 🎭 6종 복셀 캐릭터 & 전용 고유 보이스 (Playable Characters)

인게임 **[🎭 캐릭터 선택]** 팝업을 통해 언제든 원하는 캐릭터로 즉시 교체하여 플레이할 수 있으며, 마지막 선택은 `localStorage`에 자동 저장됩니다.

1. **🐔 꼬꼬닭 (Chicken)**: 시그니처 오리지널 닭, 통통 튀는 뿅뿅 뜀박질 사운드
2. **🦆 청둥오리 (Duck)**: 에메랄드빛 머리와 주황 부리, 경쾌한 꽥꽥(Quack) 사운드
3. **🐦 도시 비둘기 (Pigeon)**: 회색 깃털과 목 띠 장식, 은은한 구구(Coo) 사운드
4. **🐸 청개구리 (Frog)**: 튀어나온 똘망똘망한 눈망울, 찰진 개굴개굴(Ribbit) 사운드
5. **🤖 레트로 봇 (Robot)**: 금속 바디와 반짝이는 안테나, 레트로 8-bit 전자 비프음
6. **🐱 삼색 야옹이 (Cat)**: 쫑긋 선 귀와 줄무늬 꼬리, 귀여운 냥냥(Meow) 짹짹음

## 🌍 원작급 4대 바이옴 & 스테이지 확장 (Biomes & Stages)

점수가 올라갈 때마다 환경, 하늘색, 조명, 지형, 특수 오브젝트가 실시간으로 변화합니다!

1. **🌲 초원 (Grassland)**
   - 싱그러운 파스텔톤 초원과 단풍/푸른잎 나무, 일반 도로와 강물
2. **🏜️ 사막 협곡 (Canyon & Desert)**
   - 황금빛 모래 지형, 팔 달린 복셀 선인장, 비포장 흙길과 황톳빛 급류
3. **❄️ 설원 툰드라 (Frozen Tundra)**
   - 눈 덮인 하얀 대지와 설원 전나무, **밟으면 1칸 미끄러지는 빙판(Ice) 레인**
4. **🌃 나이트 하이웨이 (Night City)**
   - 밤하늘과 가로등, 경광등이 번쩍이는 **🚨경찰차**와 초고속 **🏎️스포츠카**가 질주하는 다차선 아스팔트

## ✨ 핵심 기능 (Features)

- **다채로운 캐릭터 로스터**: 6종의 정교한 복셀 모델 및 전용 Web Audio 신시사이저 보이스
- **정통 쿼터뷰 아이소메트릭 시점**: 플레이어 등 뒤 대각선 위에서 우상단을 바라보는 원작 100% 일치 앵글
- **키 씹힘 없는 쾌속 입력 버퍼링**: 점프 도중 입력도 저장되어 연타 시 즉각 반응
- **빙판 미끄러짐 물리**: 얼음 타일에 착지 시 미끄러지는 스릴 넘치는 손맛
- **카메라 자동 전진 & 독수리 급강하**: 화면 하단으로 밀려나면 저 멀리 하늘에서 거대 독수리가 급강하하여 낚아챔
- **풍부한 파티클 시스템**: 깃털 폭발, 물보라, 흙먼지, 얼음 파편
- **황금 코인 시스템**: 회전하는 황금 코인 수집 및 카운터
- **사운드 On/Off 토글**: 상단 버튼으로 언제든 음소거 가능

---

## 🛠️ 조작 방법 (Controls)

- **PC 키보드**: W / ↑ (전진), S / ↓ (후진), A / ← (좌), D / → (우)
- **모바일/터치**: 화면 탭(전진), 스와이프(상하좌우 이동)
- **캐릭터 변경**: 상단 좌측 `[🎭 캐릭터 선택]` 버튼 또는 게임 오버 화면의 `[🎭 캐릭터 변경]` 버튼
- **음소거**: 상단 우측 🔊 / 🔇 버튼
- **재시작**: Space 키 또는 재시작 버튼
